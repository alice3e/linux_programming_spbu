# Документация пользователя для демона резервного копирования

## Описание

Данный демон предназначен для автоматического регулярного резервного копирования данных из одного каталога в другой. Он позволяет настраивать параметры резервного копирования через графический интерфейс, обеспечивая простоту использования.

## Установка

1. **Убедитесь, что у вас установлен Python**: Убедитесь, что у вас установлен Python 3. Для проверки в терминале выполните:
   ```bash
   python3 --version
   ```

2. **Установите необходимые зависимости**: Убедитесь, что библиотеки `tkinter`, `json`, `shutil`, `logging`, `datetime` и `threading` доступны в вашей среде Python. Обычно они уже установлены вместе с Python.

3. **Запустите приложение**: Сохраните код в файл, например, `backup_daemon.py`, и запустите его с помощью команды:
   ```bash
   python3 backup_daemon.py
   ```

## Настройки

При первом запуске откроется графический интерфейс, где можно настроить параметры резервного копирования:

1. **Source Directory (Исходный каталог)**: Укажите полный путь к каталогу, файлы которого необходимо резервировать.

2. **Backup Directory (Каталог резервных копий)**: Укажите полный путь к каталогу, в который будут сохраняться резервные копии.

3. **Backup Interval (Интервал копирования в секундах)**: Укажите, с какой периодичностью (в секундах) необходимо выполнять резервное копирование.

4. **Log File (Файл журнала)**: Статически задается как `lesson2/backup_daemon.log`. В этом файле будут храниться записи о выполнении резервного копирования.

## Команды управления

1. **Save Configuration (Сохранить конфигурацию)**: Нажмите эту кнопку, чтобы сохранить введенные настройки в файл конфигурации `lesson2/backup_config.json`.

2. **Run Backup Daemon (Запустить демон резервного копирования)**: После сохранения конфигурации нажмите эту кнопку, чтобы запустить демон резервного копирования. Он будет работать в фоновом режиме, выполняя резервное копирование согласно заданному интервалу.

3. **Stop Backup Daemon (Остановить демон резервного копирования)**: Нажмите эту кнопку, чтобы остановить демон, если он работает.

## Процесс резервного копирования

1. После запуска демона он будет периодически выполнять резервное копирование, копируя все содержимое исходного каталога в каталог резервных копий с добавлением временной метки в название папки резервной копии.

2. Все операции будут записываться в файл журнала, где можно будет увидеть результаты выполнения резервного копирования, а также любые ошибки, которые могут возникнуть.

## Пример использования

1. Откройте графический интерфейс.
2. Введите путь к исходному каталогу, например: `/path/to/source/`.
3. Введите путь к каталогу резервных копий, например: `/path/to/backup/`.
4. Установите интервал, например: `3600` (для копирования каждый час).
5. Нажмите "Save Configuration" для сохранения настроек.
6. Нажмите "Run Backup Daemon" для запуска процесса резервного копирования.
7. Чтобы остановить резервное копирование, нажмите "Stop Backup Daemon".
